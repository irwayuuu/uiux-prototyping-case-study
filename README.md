# UI/UX Interactive Prototyping Case Study

User-centered design documentation, research analysis, wireframing, and usability evaluation model developed for UNIMAS Human-Computer Interaction (HCI) coursework.

## 📂 Files Included
* **`Main.java`** - Usability test metrics and task evaluation simulation runner.
* **`UsabilityTask.java`** - Core model class tracking task completion times, descriptions, and evaluation statuses.
